Soul Search is a lightweight, single-file Python 3 and GTK 3 Windows-style spotlight launcher (soul_spotlight.py) designed for Linux Mint Cinnamon that maintains a background daemon via Unix signals for instant 0ms popup speed, offering prefix-first app indexing, immediate = math evaluation, and direct Google Chrome web searches; it requires Python 3, GTK 3 bindings (python3-gi, gir1.2-gtk-3.0), and Google Chrome, and you can set it up by saving the script into ~/.local/share/soul-search, running chmod +x ~/.local/share/soul-search/soul_spotlight.py, freeing up shortcut keys via gsettings set org.freedesktop.ibus.general.hotkey triggers "['']" and gsettings set org.cinnamon.desktop.keybindings.wm switch-input-source "['']", assigning Win + Space to execute $HOME/.local/share/soul-search/soul_spotlight.py --toggle through your keyboard settings or terminal, and optionally adding a startup entry in ~/.config/autostart/ so it runs seamlessly from boot.
